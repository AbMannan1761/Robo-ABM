# 🌌 Stonic JARVIS — Sci-Fi Desktop AI Companion

**Stonic JARVIS** হলো [Stonic AI](https://stonicai.com/) এর আর্কিটেকচার দ্বারা অনুপ্রাণিত একটি সম্পূর্ণ সায়েন্স-ফিকশন ডেক্সটপ এআই অ্যাসিস্ট্যান্ট। এটি একটি জীবন্ত এআই চরিত্রের মতো আপনার কম্পিউটারে কাজ করে—যার নিজস্ব কণ্ঠ, ইন্টারেক্টিভ ৩ডি পার্টিকেল অ্যাভাটার, মেমোরি এবং উইন্ডোজ পিসি নিয়ন্ত্রণের ক্ষমতা রয়েছে।

---

## 🚀 মূল ফিচারসমূহ (Key Features)

1. **হলোওগ্রাফিক ৩ডি পার্টিকেল অ্যাভাটার (Three.js WebGL):**
   - হাজার হাজার নিয়ন কণা দিয়ে গঠিত জীবন্ত এআই কোর।
   - এটি সিস্টেমের অবস্থার ওপর নির্ভর করে প্রতিক্রিয়া জানায়:
     - `IDLE`: শান্তভাবে শ্বাস নেওয়ার মতো স্পন্দন।
     - `LISTENING`: গ্রিন নিয়ন রেসোনেন্স।
     - `THINKING`: দ্রুত আবর্তিত পার্পল স্পাইরাল।
     - `SPEAKING`: এআই-এর কণ্ঠের অডিও ফ্রিকোয়েন্সি (Web Audio Analyser) অনুযায়ী তরঙ্গাকারে স্পন্দিত হয়।
2. **ওয়ার্ল্ড মনিটর ও ৩ডি স্যাটেলাইট গ্লোব:**
   - সক্রিয় হটস্পট ও রাডার স্ক্যানিং সহ ৩ডি গ্লোব।
   - লাইভ ইউটিসি (UTC) ও লোকাল টাইম ডিসপ্লে।
3. **লাইভ সিস্টেম টেলিমেট্রি ও গেজ (System Telemetry HUD):**
   - রিয়েল-টাইম CPU ইউটিলাইজেশন, RAM খরচ, হার্ডডিস্ক ও ব্যাটারি লেভেল মনিটরিং।
4. **হাই-কোয়ালিটি নিউরাল ভয়েস সিন্থেসিস (Neural TTS):**
   - মাইক্রোসফটের আধুনিক নিউরাল ভয়েস ইঞ্জিন (Edge-TTS) ইন্টিগ্রেটেড।
   - ইংরেজি JARVIS ভয়েস (`ChristopherNeural`, `GuyNeural`, `AriaNeural`) এবং বাংলা ভয়েস (`PradeepNeural`, `NabanitaNeural`) সাপোর্ট।
5. **উইন্ডোজ পিসি অটোমেশন (OS Tool Dispatch):**
   - ভয়েস বা টেক্সটে অ্যাপ চালু করা (Chrome, Spotify, VS Code, Notepad, ইত্যাদি)।
   - ইউটিউব বা গুগলে সরাসরি সার্চ ও গান প্লে করা।
   - সাউন্ড কন্ট্রোল (ভলিউম বাড়ানো, কমানো, মিউট করা)।
   - সিস্টেমের অবস্থা ডায়াগনস্টিকস।
6. **লোকাল মেমোরি সিস্টেম (Persistent Memory):**
   - ইউজারের নাম ("My name is ..."), পছন্দ এবং অতীতের কথোপকথন লোকাল স্টোরেজে সংরক্ষণ করে।
7. **অফলাইন অটোনোমাস ব্রেন + ক্লাউড এলএলএম অপশন:**
   - কোনো পেইড এপিআই কি (API Key) ছাড়াই এটি বিল্ট-ইন JARVIS ইঞ্জিনে অফলাইনে কাজ করে। চাইলে সেটিংসে OpenAI বা Gemini API Key যোগ করা যায়।

## ⚡ কীভাবে চালাবেন (How to Run)

### সবচেয়ে সহজ উপায় (১-ক্লিকে):
ফোল্ডারে থাকা **`start_all.bat`** ফাইলে ডাবল ক্লিক করুন।
এটি স্বয়ংক্রিয়ভাবে:
1. ব্যাকএন্ড সার্ভার চালু করবে (Port 5800)।
2. ফ্রন্টএন্ড HUD চালু করবে (Port 5173)।
3. আপনার ব্রাউজারে `http://localhost:5173` ওপেন করে দেবে।

### ম্যানুয়ালভাবে চালাতে চাইলে:
১. **ব্যাকএন্ড চালু করুন:**
   ```bash
   cd server
   python main.py
   ```
২. **ফ্রন্টএন্ড চালু করুন:**
   ```bash
   cd client
   npm run dev
   ```
   এরপর ব্রাউজারে `http://localhost:5173` এ যান।

## 🎙️ কিছু নমুনা কমান্ড (Example Commands)

মাইক্রোফোন বাটনে ক্লিক করে বা প্রম্পট বারে লিখে কমান্ড দিন:
- *"Open Chrome"* অথবা *"খুলো Chrome"*
- *"Play Interstellar soundtrack on YouTube"*
- *"System status"* অথবা *"পিসির অবস্থা"*
- *"Volume up"* / *"Volume down"* / *"Mute"*
- *"My name is Tony"* (সে আপনার নাম মনে রাখবে)
- *"Who are you?"*

সেটিংস আইকনে ক্লিক করে আপনি ভয়েস পরিবর্তন করতে পারেন (ইংরেজি JARVIS অথবা বাংলা প্রদীপ/নবনিতা)।
